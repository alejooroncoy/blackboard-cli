Lo esencial sobre qué es cada producto y quién está detrás.

¿Campus CLI y Campus Profes son el mismo producto?

No. Son dos productos independientes de Campus. Campus CLI conecta tu Aula Virtual (Blackboard UPC) con ChatGPT, Claude o la terminal. Campus Profes es un bot de WhatsApp para elegir profesor antes de matricularte. Puedes usar uno, el otro, o ambos.

¿Cuál debería usar?

Si quieres consultar tus cursos, tareas y notas de Blackboard, usa Campus CLI. Si estás por matricularte y quieres saber cómo califican a un profesor, usa Campus Profes.

¿Quién está detrás de Campus?

Campus lo construye Alejandro Oroncoy, estudiante de Ingeniería de Software en la UPC. Puedes leer por qué construyó cada producto en el blog.

¿Es lo mismo que el paquete "campus-cli" de PyPI u otras apps de IA para estudiantes?

No. El paquete campus-cli de PyPI es un proyecto de Python no relacionado (gestión de archivos de notebooks Jupyter). Tampoco somos las plataformas de "IA para resolver tareas" que usan nombres parecidos. Este Campus es el paquete campus-cli de npm — el código fuente está en github.com/alejooroncoy/campus-cli.
