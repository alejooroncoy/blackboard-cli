Blackboard CLI · Open source

Blackboard, directo en tu terminal.

Blackboard CLI te permite iniciar sesión y consultar tu Blackboard UPC con comandos simples. Úsalo cuando quieras trabajar rápido, automatizar consultas o conectar tu flujo con herramientas de IA.

npm install -g campus-cli@2.0.0
campus login
campus courses
campus assignments
campus grades
Ver el repositorio

Comandos disponibles

  • campus login: autentica tu sesión institucional.
  • campus courses: lista tus cursos.
  • campus assignments: muestra tareas y fechas.
  • campus grades: consulta tus calificaciones.

Blackboard CLI + MCP

El CLI es para trabajar desde la terminal. El servidor Blackboard MCP permite que asistentes compatibles utilicen las mismas herramientas de Campus desde un chat. Puedes elegir la interfaz que encaje mejor con tu flujo; para saber qué revisar cada semana antes de automatizarlo, lee la guía para organizar tu semana en Blackboard sin perder fechas.

¿Y si no usas la terminal?

El CLI es gratis y de código abierto, pero necesita Node.js y una línea de comandos, y solo funciona con clientes de escritorio. Si prefieres preguntar desde ChatGPT o Claude en el navegador, o desde el móvil, esa es la versión de Campus que no instalas nada.

Importante

Campus es un proyecto independiente y no está afiliado a Blackboard ni UPC. La compatibilidad actual está enfocada en Blackboard UPC. Revisa el repositorio para la documentación y cambios más recientes.
