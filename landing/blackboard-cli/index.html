Blackboard CLI · Open source

Blackboard, directo en tu terminal.

Blackboard CLI te permite iniciar sesión y consultar tu Blackboard UPC con comandos simples. Úsalo cuando quieras trabajar rápido, automatizar consultas o conectar tu flujo con herramientas de IA.

npm install -g campus-cli
campus account login
campus courses list
campus assignments list --pending
campus courses grades <courseId>
Ver el repositorio

En resumen

  • Qué es: el mismo motor que Blackboard MCP, pero por comandos en vez de por chat. Un solo login sirve para los dos modos.
  • Instalación: npm install -g campus-cli, o sin instalar nada con npx campus-cli.
  • Requisitos: Node.js 18 o superior y una cuenta activa de UPC con acceso a Aula Virtual.
  • Para quién: quien prefiere la consola, quiere automatizar con --json o va a encadenar Campus con otras herramientas.
  • Licencia: código abierto, publicado en npm como campus-cli.

Instalación y primer uso

El login abre el navegador y encadena el SSO de Microsoft de UPC, con MFA si tu cuenta lo pide. Todo corre en tu máquina: no pasa por ningún servidor de Campus, y lo que queda guardado es una sesión, no tu contraseña.

Si Microsoft muestra «Stay signed in?», marca la casilla y acepta — así la sesión se mantiene y no repites el login cada día.

Comandos disponibles

ComandoQué hace
campus account loginInicia sesión y encadena el login de Blackboard.
campus whoamiUsuario activo y tiempo restante de sesión.
campus statusSesión y versión del servidor Blackboard.
campus courses listLista tus cursos del ciclo.
campus courses contents <courseId>Materiales y carpetas del curso.
campus courses announcements <courseId>Anuncios publicados por el profesor.
campus courses grades <courseId>Reporte de calificaciones del curso.
campus assignments list --pendingTareas pendientes de todos tus cursos.
campus assignments submit <courseId> <id> -f tarea.pdfEntrega una tarea; --draft guarda sin enviar.
campus download-folder <courseId> <folderId> -o ./materiales/Descarga una carpeta completa.
campus api GET /learn/api/public/v1/users/meLlamada directa a cualquier endpoint de Blackboard.
campus mcpArranca el servidor MCP por stdio.

Los IDs de curso tienen la forma _100001_1. Todos los comandos aceptan --json, y los spinners van a stderr, así que --json 2>/dev/null te da JSON limpio para scripts.

¿CLI o MCP?

ModoCuándo conviene
CLIConsultas rápidas, scripts, automatización, no salir de la terminal.
MCPDarle a un asistente de IA acceso al campus: «¿qué tengo pendiente esta semana?»

No hay que elegir: los dos modos comparten la misma sesión. Primero campus account login, después el CLI a mano o el servidor MCP conectado a tu cliente de IA. Para saber qué revisar cada semana antes de automatizarlo, lee la guía para organizar tu semana en Blackboard sin perder fechas.

Preguntas frecuentes

¿Necesito instalarlo para probarlo?

No. npx campus-cli account login lo descarga y ejecuta sin instalación global.

¿Guarda mi contraseña de UPC?

No. El login usa el flujo estándar de Microsoft SSO en tu navegador. Queda guardada una sesión local, revocable con campus logout.

¿Puedo usarlo en scripts?

Sí. Todos los comandos aceptan --json y los mensajes de progreso van a stderr.

¿Funciona en Windows?

Sí, en macOS, Linux y Windows, siempre que el entorno permita a Playwright abrir Chromium para el login.

¿Está afiliado a Blackboard o UPC?

No. Campus es un proyecto independiente y no oficial. La compatibilidad actual está enfocada en Blackboard UPC; Canvas y Moodle están en el roadmap. El repositorio tiene la documentación y los cambios más recientes.
