Blackboard MCP · Campus

Tu Blackboard UPC, disponible para tu asistente de IA.

Blackboard MCP conecta tu campus virtual con asistentes compatibles con Model Context Protocol. Pregunta por tus cursos, tareas, notas y anuncios sin buscar manualmente entre pestañas.

En resumen

  • Qué es: un servidor MCP que expone Blackboard Learn como herramientas estándar, para que un asistente de IA consulte tu campus por ti. Se instala con npx campus-cli mcp.
  • Para quién: estudiantes. A diferencia de las integraciones institucionales de Blackboard, no necesita credenciales OAuth del administrador del LMS: usa tu propia sesión de Aula Virtual.
  • Qué expone: 19 herramientas blackboard_* — cursos, tareas con fechas, notas, feedback del profesor, anuncios, materiales, descargas, borradores y entrega con confirmación.
  • Dónde funciona: Claude Desktop, Claude Code, Cursor, GitHub Copilot, Codex CLI y Windsurf. Corre localmente por stdio.
  • Alcance actual: Blackboard UPC (Perú). Canvas y Moodle están en el roadmap. Proyecto independiente, no afiliado a UPC ni a Blackboard.

¿Qué es Blackboard MCP?

Model Context Protocol (MCP) es un estándar abierto que define cómo un asistente de IA descubre y usa herramientas externas. Un servidor MCP de Blackboard traduce la API de Blackboard Learn a esas herramientas, de modo que el asistente pueda pedir «los cursos de este estudiante» o «las tareas pendientes de este curso» y recibir datos estructurados en vez de HTML.

Campus es un servidor MCP de Blackboard hecho para el estudiante, no para el administrador de la plataforma. No necesitas que la universidad te entregue credenciales de API: usas tu propia sesión de Aula Virtual, la misma con la que entras al campus todos los días.

Qué puedes preguntar

  • «¿Qué tareas tengo pendientes esta semana y cuáles pesan más?»
  • «¿Cuál es mi nota actual en Arquitectura de Software y qué me falta?»
  • «Descarga los PDFs de la semana 8 de Finanzas y resúmelos.»
  • «¿Qué anunció el profesor de Bases de Datos desde el lunes?»
  • «Lee el enunciado del trabajo parcial y dime qué me falta cubrir.»

La diferencia con copiar y pegar en el chat es que el asistente abre el material él mismo. Ese contraste está medido en la guía sobre cuánto tiempo pierdes copiando archivos de Blackboard a ChatGPT a mano.

Cómo conectarlo en 3 pasos

Necesitas Node.js 18 o superior, una cuenta activa de UPC con acceso a Aula Virtual y un cliente compatible con MCP. Toma unos cinco minutos, una sola vez.

  1. Inicia sesión. En tu terminal, ejecuta el login. Se abre el navegador con el SSO de Microsoft de UPC, incluido MFA si tu cuenta lo pide.
  2. Registra el servidor en el archivo de configuración de tu cliente de IA, con el bloque de abajo.
  3. Reinicia el cliente y pregunta en lenguaje natural. Las herramientas aparecen disponibles automáticamente.
npx campus-cli account login

Y la configuración mínima, común a todos los clientes:

{
  "mcpServers": {
    "campus": {
      "command": "npx",
      "args": ["campus-cli", "mcp"]
    }
  }
}

El formato exacto y la ruta del archivo cambian según el cliente. Elige el tuyo abajo para ver los pasos concretos.

Herramientas disponibles

Estas son las herramientas que el asistente puede usar. Todas llevan el prefijo blackboard_ para no chocar con futuros conectores de Canvas o Moodle.

HerramientaQué hace
blackboard_whoamiConfirma qué cuenta está autenticada.
blackboard_list_coursesLista tus cursos del ciclo.
blackboard_get_courseDetalle de un curso concreto.
blackboard_list_contentsRecorre materiales y carpetas del curso.
blackboard_list_announcementsAnuncios publicados por el profesor.
blackboard_list_assignmentsTareas con fecha de entrega, peso y nota.
blackboard_list_attemptsHistorial de entregas de una actividad.
blackboard_get_gradesReporte completo de notas del curso.
blackboard_get_assignment_feedbackPuntajes, comentarios y archivos de feedback del profesor.
blackboard_list_attachmentsArchivos adjuntos dentro de un contenido.
blackboard_download_attachmentDescarga un archivo a tu equipo.
blackboard_upload_attempt_fileSube un archivo local para adjuntarlo a una entrega.
blackboard_save_attempt_draftGuarda un borrador sin enviarlo; el intento queda abierto.
blackboard_submit_attemptEnvía la entrega final. Siempre pide tu confirmación antes.
blackboard_system_versionVersión del servidor Blackboard.
blackboard_list_peopleDocentes y compañeros del curso; resuelve un id interno a un nombre real.
blackboard_download_file_urlDescarga un archivo directamente desde una URL bbcswebdav de Blackboard.
blackboard_download_feedback_fileDescarga un archivo de feedback que el profesor adjuntó a una nota. Experimental.
blackboard_raw_apiCualquier otro endpoint de la API de Blackboard.

Seguridad y privacidad

El login corre en tu propia máquina: se abre el flujo estándar de Microsoft SSO en un navegador real, tú escribes tus credenciales ahí y completas MFA como siempre. Campus no ve ni almacena tu contraseña de UPC. Lo que queda en tu equipo es una sesión, que puedes cerrar cuando quieras.

El servidor MCP corre localmente por stdio: los datos de tu campus viajan entre tu equipo y Blackboard, no a través de un servidor intermedio de Campus. Y el envío de una entrega nunca ocurre en silencio — blackboard_submit_attempt exige confirmación explícita, mientras que guardar un borrador no la necesita.

Qué no hace

Vale la pena ser explícito. Campus no reemplaza al Aula Virtual: tu campus institucional sigue siendo la fuente oficial y la única válida para plazos y calificaciones. No resuelve tus tareas por ti, no envía nada sin que lo autorices y hoy no soporta los cuestionarios interactivos de Blackboard Ultra, solo las entregas de archivo, texto o enlace. Canvas y Moodle todavía no están implementados.

Campus frente a una integración genérica de Blackboard

Existen otros servidores MCP para Blackboard Learn, pensados para instituciones: envuelven la API oficial y necesitan credenciales OAuth2 emitidas por el administrador del LMS, con roles de docente o de sistema. Son buenos para el equipo de TI de una universidad y sirven de poco a un estudiante, que nunca va a recibir esas llaves.

El panorama completo — institucionales, de estudiante, proyectos por universidad y el homónimo que no es un LMS — está ordenado en la comparativa de servidores MCP para Blackboard.

Campus parte del lado contrario. Empieza por la sesión que ya tienes y por el flujo real de la semana: qué debo entregar, cuánto llevo, qué material necesito leer. Ese recorrido está descrito paso a paso en la guía para organizar tu semana en Blackboard sin perder fechas. Y si prefieres la consola antes que un chat, la misma información está en Blackboard CLI, el cliente de terminal de Campus.

Preguntas frecuentes

¿Qué es Blackboard MCP?

Es un servidor que expone tu Blackboard Learn como herramientas estándar de Model Context Protocol, para que un asistente de IA compatible las use en una conversación normal.

¿Qué puede consultar?

Cursos inscritos, tareas con fechas de entrega, notas y feedback del profesor, anuncios, materiales y archivos adjuntos de Blackboard UPC.

¿Con qué asistentes funciona?

Con cualquier cliente compatible con MCP: Claude Desktop, Claude Code, Cursor, GitHub Copilot en VS Code, OpenAI Codex CLI y Windsurf, entre otros.

¿En qué se diferencia de una integración genérica de Blackboard?

Las integraciones genéricas apuntan a administradores e instituciones y requieren credenciales de API otorgadas por la universidad. Campus parte de la sesión del propio estudiante y de sus flujos reales: qué debo entregar, cuánto llevo, qué material necesito.

¿Guardan mi contraseña de UPC?

No. El login usa el flujo normal de Microsoft SSO en tu navegador, de forma local. Queda guardada una sesión, no tu contraseña.

¿Puede entregar tareas por mí?

Puede subir archivos y guardar borradores. El envío final siempre pide tu confirmación explícita.

¿Necesito saber programar?

No para usarlo. Pegas un bloque de configuración una vez y después preguntas en lenguaje natural.

¿Funciona en otras universidades?

Hoy solo Blackboard UPC está implementado. Canvas y Moodle están en el roadmap.

¿Es gratis?

El código es abierto, en GitHub y npm. El acceso anticipado acompañado, con soporte directo, cuesta S/20 por dos meses.

¿Campus está afiliado a Blackboard o UPC?

No. Campus es un proyecto independiente y no oficial, compatible hoy con Blackboard UPC.

¿Puedo tener problemas con mi universidad por usarlo?

Campus es una herramienta de terceros que usa tu sesión institucional, y eso es algo que cada universidad regula por su cuenta. Revisa el reglamento de uso de tu cuenta y de los servicios del campus antes de conectarla. Aparte de eso, vale la pena decir lo obvio: consultar tus tareas y materiales es una cosa, y hacer que una IA resuelva por ti una evaluación es otra, con las reglas de integridad académica de tu carrera de por medio.
