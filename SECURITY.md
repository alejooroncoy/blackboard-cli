# Security policy

## Supported versions

Security fixes are provided for the latest published minor version of
`campus-cli`. Users should pin that version in MCP configuration and update the
pin after reviewing each release.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability involving credentials,
session cookies, local file access, assignment submission, or authenticated
Blackboard requests. Use GitHub's private vulnerability reporting for this
repository instead:

https://github.com/alejooroncoy/campus-cli/security/advisories/new

Include the affected version, prerequisites, impact, and the smallest safe
reproduction you can provide. Do not include real student credentials, cookies,
grades, submissions, or personal information.
